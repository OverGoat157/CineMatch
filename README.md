# Название проекта
**«CineMatch»** 

## Назначение
«CineMatch» — это интеллектуальный онлайн-сервис для подбора фильмов и сериалов. Основная задача приложения — помочь пользователю быстро найти контент, который ему понравится, основываясь на его вкусах, настроении или случайном выборе. Сервис решает проблему «вечернего поиска», когда на выбор фильма уходит больше времени, чем на его просмотр.

## Целевая аудитория
- **Киноманы и меломаны**, следящие за новинками и шедеврами мирового кинематографа.
- **Люди, испытывающие трудности с выбором** (синдром «что бы посмотреть»).
- **Занятые люди**, которые хотят доверить выбор алгоритму, чтобы провести вечер за качественным контентом.
- **Компании друзей**, ищущие фильм, который устроит всех (режим группового выбора).

## Предметная область
Сфера **цифровых развлечений** и **кинопроката** (VOD — Video on Demand). Область включает в себя работу с базами данных киноконтента, метаданными (жанры, режиссеры, актеры, год выпуска), пользовательскими предпочтениями и рейтингами. Ключевая задача — применение алгоритмов коллаборативной и контентной фильтрации для построения рекомендаций.

## Основные сущности
- **Фильм/Сериал** (название, описание, жанры, рейтинг, постер, год выпуска, режиссер, актерский состав, длительность).
- **Пользователь** (уникальный логин, история просмотров, список "любимых" жанров, персональный рейтинг фильмов).
- **Рекомендательная сессия** (параметры текущего поиска: жанр, эпоха, настроение, уровень известности).
- **Отзыв/Оценка** (пользовательская оценка фильма, текстовый комментарий, дата просмотра).

## Основные функции
- **Каталог фильмов** — просмотр карточек, поиск по названию, отбор по жанру, сортировка по рейтингу, добавление фильма.
- **Пользователи** — список пользователей, добавление, выбор текущего пользователя.
- **Оценки** — оценка фильма текущим пользователем от 1 до 10, запрет повторной активной оценки, отмена оценки (запись сохраняется с признаком отмены), просмотр оценок.
- **Рекомендации** — подбор неоценённых фильмов под любимый жанр и минимальный рейтинг пользователя, случайный совет на вечер.
- **Статистика** — количество фильмов по жанрам.

## Классы предметной области
Классы находятся в пакете `models/`.

### Movie — фильм (`models/movies.py`)
Атрибуты: `id`, `title`, `genre`, `year`, `rating`, `duration`.
Методы:
- `has_genre(genre)` — проверка жанра без учёта регистра;
- `get_age()` — возраст фильма в годах;
- `from_data(data)` — создание объекта из данных JSON (`@classmethod`);
- `__str__()` — карточка фильма.

### User — пользователь (`models/users.py`)
Атрибуты: `id`, `name`, `favorite_genre`, `min_rating`.
Методы:
- `get_recommendation(movie)` — вердикт по фильму (логика из ПР1);
- `likes(movie)` — полностью ли фильм подходит пользователю;
- `from_data(data)` — создание объекта из данных JSON;
- `__str__()` — строковое представление.

### Rating — оценка (`models/ratings.py`)
Атрибуты: `id`, `movie` (объект `Movie`), `user` (объект `User`), `score`, `is_cancelled`.
Методы:
- `cancel()` — отмена оценки без удаления из коллекции;
- `validate_score(score)` — проверка диапазона оценки (`@staticmethod`);
- `__str__()` — описание оценки с учётом состояния.

### Взаимодействие объектов
`User` ставит `Rating` фильму `Movie`. Объект `Rating` хранит ссылки на `Movie` и `User`, поэтому данные связанных объектов доступны напрямую: `rating.movie.title`, `rating.user.name`. Один пользователь не может иметь две активные оценки одного фильма; отменённая оценка не мешает поставить новую. Рекомендации строятся методом `user.likes(movie)` по фильмам без активной оценки этого пользователя.

Функции работы с коллекциями объектов (`add_movie`, `find_movies`, `sort_movies`, `rate_movie`, `cancel_rating`, `recommend_movies` и другие) остаются обычными функциями в модулях пакета `models`.

## Формат данных
Данные хранятся в каталоге `data/`. При загрузке записи JSON превращаются в объекты `Movie`, `User` и `Rating`, при сохранении объекты преобразуются обратно. В `ratings.json` вместо объектов хранятся идентификаторы `movie_id` и `user_id`, по которым при загрузке восстанавливаются ссылки.

`data/movies.json`:
```json
[{"id": 1, "title": "Интерстеллар", "genre": "Фантастика", "year": 2014, "rating": 8.6, "duration": 169}]
```

`data/users.json`:
```json
[{"id": 1, "name": "Алексей", "favorite_genre": "Фантастика", "min_rating": 8.0}]
```

`data/ratings.json`:
```json
[{"id": 1, "movie_id": 1, "user_id": 1, "score": 9, "is_cancelled": false}]
```

## Требования
- Python 3.10+;
- pytest;
- flake8.

Установка зависимостей:
```
pip install -r requirements.txt
```

## Запуск программы
```
python main.py
```

## Тестирование
```
pytest -v
```
Тесты проверяют создание объектов и их атрибуты, строковое представление, методы классов, операции с каталогом, правила оценивания (запрет повторной оценки, отмена) и подбор рекомендаций.

flake8

## План развития
На следующих этапах планируется:
- Фильтрация по параметрам (поиск по жанру, году, стране, актеру, длительности и наличию награды "Оскар").
- "Что посмотреть сегодня вечером?" пресетные подборки (например, "Пикник", "Дождь за окном", "Финал Чемпионата" — чтобы отвлечься).
- Интеллектуальный подбор (генерация персональных рекомендаций на основе истории оценок пользователя).
- разработка веб-приложения (адаптивный UI/UX с акцентом на визуальное отображение постеров);
- подключение базы данных (PostgreSQL для хранения профилей и MongoDB для гибкой схемы фильмов);
- реализация пользователей (регистрация, авторизация, верификация, сохранение "Избранного");
- разработка API (RESTful API для мобильного приложения и фронтенда, а также интеграция с внешними источниками данных, например, TMDB или Kinopoisk API);
- контейнеризация приложения (Docker и Docker Compose для изоляции сервисов рекомендаций и бэкенда);
- настройка CI/CD (автоматическое тестирование и деплой на сервер при пуше в основную ветку репозитория).
