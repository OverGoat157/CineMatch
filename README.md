# Название проекта
**«CineMatch»** 

## Назначение
«CineMatch» — это интеллектуальный онлайн-сервис для подбора фильмов и сериалов. Основная задача приложения — помочь пользователю быстро найти контент, который ему понравится, основываясь на его вкусах, настроении или случайном выборе. Сервис решает проблему «вечернего поиска», когда на выбор фильма уходит больше времени, чем на его просмотр.

## Целевая аудитория
- **Киноманы и меломаны**, следящие за новинками и шедеврами мирового кинематографа.
- **Люди, испытывающие трудности с выбором** (синдром «что бы посмотреть»).
- **Занятые люди**, которые хотят доверить выбор алгоритму, чтобы провести вечер за качественным контентом.
- **Компании друзей**, ищущие фильм, который устроит всех (режим группового выбора).

## Предметная область
Сфера **цифровых развлечений** и **кинопроката** (VOD — Video on Demand). Область включает в себя работу с базами данных киноконтента, метаданными (жанры, режиссеры, актеры, год выпуска), пользовательскими предпочтениями и рейтингами. Ключевая задача — применение алгоритмов коллаборативной и контентной фильтрации для построения рекомендаций.

## Основные сущности
- **Фильм/Сериал** (название, описание, жанры, рейтинг, постер, год выпуска, режиссер, актерский состав, длительность).
- **Пользователь** (уникальный логин, история просмотров, список "любимых" жанров, персональный рейтинг фильмов).
- **Рекомендательная сессия** (параметры текущего поиска: жанр, эпоха, настроение, уровень известности).
- **Отзыв/Оценка** (пользовательская оценка фильма, текстовый комментарий, дата просмотра).

## Основные функции
- **Каталог фильмов** — просмотр карточек (название, год, жанр, рейтинг, длительность, возраст фильма), поиск по названию, отбор по жанру, сортировка по рейтингу, добавление фильма.
- **Оценки** — выставление оценки от 1 до 10, запрет повторной оценки, отмена оценки, просмотр своих оценок.
- **Рекомендации** — подбор неоценённых фильмов под любимый жанр и минимальный рейтинг пользователя, случайный совет на вечер.
- **Статистика** — количество фильмов по жанрам.

## Структура проекта
- `main.py` — точка запуска, цикл меню;
- `movies.py` — работа с каталогом фильмов (добавление, поиск, фильтр, сортировка, карточка);
- `ratings.py` — оценки и рекомендации;
- `storage.py` — загрузка и сохранение JSON-файлов;
- `utils.py` — безопасный ввод чисел;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты pytest.

## Формат данных
Данные хранятся в каталоге `data/` и загружаются при запуске.

`data/movies.json` — список фильмов:
```json
[{"id": 1, "title": "Интерстеллар", "genre": "Фантастика", "year": 2014, "rating": 8.6, "duration": 169}]
```

`data/ratings.json` — список оценок пользователя:
```json
[{"movie_id": 1, "score": 9}]
```

`data/user.json` — профиль пользователя:
```json
{"name": "Алексей", "favorite_genre": "Фантастика", "min_rating": 8.0}
```

## План развития
На следующих этапах планируется:
- Фильтрация по параметрам (поиск по жанру, году, стране, актеру, длительности и наличию награды "Оскар").
- "Что посмотреть сегодня вечером?" пресетные подборки (например, "Пикник", "Дождь за окном", "Финал Чемпионата" — чтобы отвлечься).
- Интеллектуальный подбор (генерация персональных рекомендаций на основе истории оценок пользователя).
- разработка веб-приложения (адаптивный UI/UX с акцентом на визуальное отображение постеров);
- подключение базы данных (PostgreSQL для хранения профилей и MongoDB для гибкой схемы фильмов);
- реализация пользователей (регистрация, авторизация, верификация, сохранение "Избранного");
- разработка API (RESTful API для мобильного приложения и фронтенда, а также интеграция с внешними источниками данных, например, TMDB или Kinopoisk API);
- контейнеризация приложения (Docker и Docker Compose для изоляции сервисов рекомендаций и бэкенда);
- настройка CI/CD (автоматическое тестирование и деплой на сервер при пуше в основную ветку репозитория).
